# Algorithms, Data Structures & Connectionist AI

**Team:** _TBD_ · **Course:** Foundations of CS & AI (BIT, 2026–27) · **Module:** Algorithms, Data Structures & Connectionist AI

## Purpose

Beginner learning materials that explain how computers solve problems step by step (algorithms), how they organise data (data structures), and how neural networks learn from data rather than following hand-written rules (connectionist AI).

This Markdown content is the shared source for our **Study Guide**, **PPT Slides** and **Video Tutorials**.

**Intended learners:** first-year university students with no programming background. We assume school-level algebra only.

1. Pull before you start: `git pull`
2. Edit only your assigned topic file(s) and update its status line.
3. Commit with your own account. Messages should say what changed, e.g. `Add worked example to binary search`.

Personal logs and private notes must **not** be committed. This repository is public.
