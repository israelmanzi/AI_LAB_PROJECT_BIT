## Purpose and intended learners

This track introduces us and our classmates to Algorithms, Data Structures and Connectionist AI. We cover how algorithms solve problems step by step, including search, sorting, recursion and the main design strategies; how data structures such as arrays, linked lists, stacks, queues, hash tables, trees and graphs organise information so those algorithms stay efficient; and how connectionist AI builds neural networks that learn from examples, from the single perceptron through multi-layer networks and gradient descent to today's deep learning.

Each concept is tied to applications we meet every day: route finding in map apps, contact search and spell-check, undo buttons and print queues, social networks and recommendation systems, spam filtering and face unlock, and the language models behind modern chatbots.

The material is written for first-year students like most of our classmates with no Computer Science/AI/Programming background. We assume only Algebra I; pseudocode and code examples are included where necessary.
