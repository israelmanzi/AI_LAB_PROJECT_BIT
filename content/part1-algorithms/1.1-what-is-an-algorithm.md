# 1.1 What Is an Algorithm?

> **Status:** outline only · **Owner:** Tharoath · **Reviewer:** Elinna

## Learning outcomes
- Define an algorithm and list its properties (finite, unambiguous, has input and output).
- Explain the difference between an algorithm and a program.
- Write simple pseudocode and read a flowchart.

## Key ideas
- An algorithm is a finite list of clear steps that solves a problem.
- A program is one algorithm written in a particular programming language.
- Pseudocode lets us describe steps without worrying about a language's rules.

## Terms to define
algorithm, program, pseudocode, flowchart, input, output

## Worked example (planned)
Find the largest number in `[7, 3, 9, 2]`, step by step, as pseudocode and as a flowchart.
